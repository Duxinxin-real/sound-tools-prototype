# Sound Tools prototype

Open `index.html` to review the interface and use imported audio.

## Live microphone recording

Browsers restrict microphone access on pages opened with a `file://` address. On macOS, double-click `start-local.command`; it opens the same prototype at:

`http://localhost:8877/index.html`

Keep the Terminal window open while recording, and allow microphone access when the browser asks. Closing the Terminal window stops the local preview server.

If the microphone is unavailable, **Use device recorder** lets you select or capture an audio file and continue with Speaker Cleaner, Noise Remover, or Sound Compare.
